# 无人机探索课堂

按用户指定的“智驾探索课堂”架构制作：顶部章节导航、左侧活动目录、中央交互画面、右侧探索工作台，以及本机学习记录。

公开仓库：https://github.com/gpy-04/drone-exploration-classroom

完整离线包见仓库右侧 Releases。下载 ZIP 并解压后，双击 `无人机探索课堂-双击打开.html`；请保留随包提供的整个课堂文件夹。直接下载仓库源码时，打开仓库根目录的 `index.html` 即可。

## 八关小游戏独立版

课堂的“飞行与空域”章节现可从“单独打开八关游戏”进入独立大厅。无需进入课堂，也可以直接打开 [`eight-drone-games/index.html`](eight-drone-games/index.html)。第一关包含配件与电池选配、三种飞行策略、风偏修正和手动目标取证；其他七关保留各自的操作机制。适合离线分发的独立 ZIP 可从 GitHub Releases 下载。

## 打开

直接用 Chrome / Edge 打开 `index.html`。两个模型、八关游戏和动漫杭州第一视角巡航均已打包在 `experiments/`，运行不依赖网络。

也可运行 `npm run dev`，打开 `http://127.0.0.1:4196/`。浏览器对 file URL 的本机存储处理不同，需要长期使用同一份学习记录时，建议固定使用这个本地地址。不要移动或只复制入口文件，需保留整个目录。

两个结构章节和八关实践按“预测—验证—证据—解释”学习。证据来自当前模型参数或真实游戏操作。演示实例的成绩不会被记录为自己的通关证据。

历史博物馆一次进入后直接向下浏览，左侧目录只滚动定位，不切换页面。各站先观察两个提示，再解释发现。馆末有交通、农业、应急救援三个“无人机 × 国产 AI”流程示例：通义千问辅助视觉理解，DeepSeek 整理经核验的信息；示例为本地预设内容，未调用真实 AI 服务。未来畅想文字可单独保存在当前浏览器。杭州巡航完成 4 个不同现场后自动记录。总计 21 项可记录活动；学习记录可导出 JSON 并导入恢复，没有账号或云端同步。

## 第一视角巡航

- WASD：前后左右；方向键：转向与俯仰；也可拖动画面转镜头。
- R / F：上升 / 下降；空格：悬停；E：取证；Esc：暂停。
- 屏幕提供移动、升降、悬停与拍摄按钮，触屏可拖动镜头。
- 取证要求：距离小于 68 m、速度低于 2.2 m/s、目标进入取景框、视线未被建筑遮挡，持续稳定 1.3 秒。
- 现场包含：红灯越线、车辆停在斑马线上、普通车进入本任务专用道、在允许的停车位合法停车。需要核验违规，也需要正确放行。
- “转向这处线索”只改变镜头方向，玩家仍需亲自飞行；地图也不会代飞。
- 画面为杭州地标意象与重组街区，路网、公告、号牌和车辆均属虚拟教学情境，不作为真实执法、飞行或道路管制指引。

## 开发

Node.js 22+。可 `npm install` 安装 package.json 中列出的工具，随后运行 `npm run build`。本机也可复用已有的 teardown 工具链。

构建从上级目录的 `无人机结构实验室.html`、`固定翼无人机结构实验室.html` 和 `drone-flight-lab-2d/dist/index.html` 生成课堂实验副本，不修改原文件。若这些原文件不在当前设备上，构建会保留已经交付的模型和八关游戏副本，仅重建新巡航游戏。

- `app.js`：章节、学习四步、证据、记录、导入导出和巡航接入。
- `content.js`：两个模型章节与八关的活动、问题和任务要求。
- `museum.js` / `museum.css`：中国无人机历史连续长页、真实照片、国产 AI 流程与未来畅想。`assets/museum/` 保存离线照片与来源清单。
- `bridge.js` / `embed.css`：隔离实验文档、桥接现有引擎和课堂控件。
- `patrol/`：动漫杭州三维世界、飞行、取证、核验与游戏设计说明。
- `build.mjs`：离线构建；`serve.mjs`：本地预览服务器。
- `verify.mjs`：真实浏览器验证；运行时先启动本地服务器。默认使用系统 Chrome。

运行 `npm test` 查看模型活动、八关操作、演示隔离、实际通关、巡航规则、暂停、记录、离线和响应式检查。检查记录在 `output/validation.json`，截图在 `output/`。

历史内容的来源与第三方许可见 `THIRD_PARTY_NOTICES.md`。模型是结构教学示意，照片逐张标注来源；后续机型实拍不冒充历史首代机照片。该版本尚未进行儿童试讲或学校设备实测。

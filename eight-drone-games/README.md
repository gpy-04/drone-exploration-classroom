# 无人机八关小游戏

这是一份可单独打开的八关 2D 无人机探索游戏，不需要安装软件，也不依赖在线游戏资源。

## 打开方式

双击本目录中的 `index.html`，建议使用 Chrome 或 Edge。下载 ZIP 后先解压，再打开文件。

## 八关内容

1. 组装你的无人机
2. 乘风穿过山谷
3. 开伞安全落地
4. 飞行动作积木
5. 守护城市空域
6. 同步临时管控
7. 补齐禁飞规划网
8. 追踪隐蔽黑飞源头

各关包含三种递进任务，游戏成绩保存在当前浏览器。图片与科学依据窗口中的外部资料链接需要联网打开；游戏本身可离线运行。

第一关增加了稳健巡航、快速取证、省电航线三种策略；试飞时要用方向键或屏幕按钮修正风偏，并在靠近目标后手动完成扫描与拍摄。路线绕行会影响得分，载重和飞行策略会改变电量消耗。
